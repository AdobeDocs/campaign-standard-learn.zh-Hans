# [!UICONTROL Profile Substitution] - 使用目标轮廓测试电子邮件消息

此视频介绍如何使用[!UICONTROL Profile Substitution]测试电子邮件。 它涵盖以下用例：

假定您要发送个性化的电子邮件新闻稿。 但是，在发送新闻稿之前，一位同事想要查看新闻稿，并已请求校样。 您可以使用 [!UICONTROL Profile Substitution] 功能发送验证，因为它允许您发送目标轮廓将收到的消息的确切呈现形式。

>[!VIDEO](https://video.tv.adobe.com/v/36440?captions=chi_hans&learn=on){transcript=true}

有关详细信息，请参阅详细的[产品文档](https://experienceleague.adobe.com/docs/campaign-standard/using/testing-and-sending/preparing-and-testing-messages/testing-messages-using-target.html?lang=zh-Hans)。

>[!IMPORTANT]
>
>此功能允许您向外部电子邮件地址发送轮廓个人信息。 请记住，在 Campaign Standard 中执行隐私请求（GDPR 和 CCPA）不会在外部执行该请求。
